# ⚽ SLIIT Football App

## 📌 Project Description

The **SLIIT Football App** is a full-stack web application designed to manage and support football-related activities within the SLIIT community. The system provides a centralized platform for managing football teams, players, matches, and other football-related information through a modern and user-friendly interface.

The application is developed using **React** for the frontend and **Spring Boot** for the backend, with **PostgreSQL** used for database management. The system follows a RESTful API architecture to enable communication between the frontend and backend.

### 🎯 Main Objectives

- Provide a centralized platform for SLIIT football activities.
- Manage football teams and player information.
- Display football-related information in an organized manner.
- Provide an easy-to-use and responsive user interface.
- Store and manage application data securely using a relational database.
- Demonstrate full-stack application development using modern technologies.

### 🛠️ Technologies Used

- **Frontend:** React.js
- **Backend:** Spring Boot
- **Programming Language:** Java
- **Database:** PostgreSQL
- **API:** REST API
- **Build Tool:** Maven
- **Development Tools:** IntelliJ IDEA / VS Code
- **Version Control:** Git & GitHub

### ✨ Key Features

- ⚽ Football team management
- 👤 Player management
- 🏆 Match and football-related information
- 📊 Organized football data
- 🔐 User authentication and authorization
- 📱 Responsive and user-friendly interface
- 🔄 Frontend-backend REST API integration
- 🗄️ PostgreSQL database integration

### 🏗️ Project Architecture

The application follows a **three-layer full-stack architecture**:

```text
React Frontend
      ↓
REST API
      ↓
Spring Boot Backend
      ↓
PostgreSQL Database
```

This architecture separates the user interface, business logic, and data management, making the application easier to maintain, test, and extend.

## 🚀 Purpose

This project was developed as a practical full-stack software engineering project to gain hands-on experience in **frontend development, backend development, REST API design, database management, authentication, and Git-based collaborative development**.
